# Habit Tracker

Habit Tracker is a React Native app for building consistent routines.
Create daily, weekly, or custom habits from the Schedule tab.
Use the Today tab to mark habits complete and view daily progress.
A weekly calendar and streak count make consistency easy to follow.
Habit completion data is stored in Firebase Firestore and synced in real time.
Google Sign-In keeps each user's habits private and available across devices.
The Notes tab provides a simple weekly goal and personal notepad.
Settings displays account details and provides sign-out access.
The interface is designed to be focused, simple, and easy to use every day.
Built with React Native, React Navigation, Firebase Authentication, and Firestore.
